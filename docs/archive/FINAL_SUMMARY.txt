 ISSUE RESOLVED: Command parsing with quoted arguments and paths with spaces

 PROBLEM STATEMENT
────────────────────────────────────────────────────────────────────────────────
The C2R2 server could not handle Windows commands with paths containing spaces:
  - /cmd dir "C:\Program Files"  FAILED
  - /cmd dir 'C:\Program Files (x86)'  FAILED
  - /cmd dir "..\..\Program Files (x86)"  FAILED

Root cause: split_whitespace() broke quoted arguments in both server and agent.

 SOLUTION IMPLEMENTED
────────────────────────────────────────────────────────────────────────────────
Server (c2r2-server/src/main.rs):
   Added parse_command_line() - Quote-aware argument parser
   Added reconstruct_command() - Proper command reconstruction
   Updated 6 command handlers (/cmd, /cmd_all, /download, etc.)

Agent (agent/src/argfuscator.rs):
   Added parse_command_args() - Preserves quotes during obfuscation
   Added reconstruct_command_args() - Rebuilds commands with quotes
   Updated obfuscate_command() to respect quoted arguments
   Added 6 unit tests for new functionality
